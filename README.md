# PROGRESS CRM

Собственная CRM агентства PROGRESS Digital.

- Итерация 1: воронка сделок
- Итерация 2: клиенты и контакты
- Итерация 3: лиды и заявки с Тильды
- Итерация 4: прайс услуг

## Что умеет

- Канбан-воронка сделок: 9 этапов от «Новая» до «Оплачен» / «Проиграна»
- Перетаскивание сделки между этапами мышью
- Создание, редактирование и удаление сделки: клиент, контакт, сумма, услуга, ответственный, дата закрытия, причина отказа, заметки
- Суммы по каждому этапу и итог «в работе / выиграно» в шапке
- Клиенты: список с поиском по названию, ИНН и имени контакта; реквизиты компании
- Контакты компании: добавление, редактирование, удаление
- Сделка привязана к клиенту и (по желанию) к его контакту; в карточке клиента видны все его сделки
- Лиды: заявки с форм Тильды приходят автоматически, можно добавить лид вручную; статусы «Новый», «В работе», «Сделка», «Отклонён»; UTM-метки и страница заявки
- Из лида одной кнопкой создаётся сделка: клиент (новый или существующий), контакт из заявки, сделка на первом этапе воронки

## Стек

Next.js 16 (App Router, server actions), React 19, TypeScript, Tailwind CSS 4, PostgreSQL 16, Prisma 6, dnd-kit.

## Запуск на своём компьютере

Нужен только [Docker Desktop](https://www.docker.com/products/docker-desktop/). В папке с кодом:

```bash
docker compose up -d --build  # база + CRM, первый раз несколько минут
```

CRM откроется на http://localhost:3000 с демо-сделками и прайсом. Данные хранятся в Docker и
переживают перезапуск. Обновить до свежего кода: скачать его заново и повторить команду.

## Разработка

```bash
docker compose up -d db       # PostgreSQL на localhost:5432
cp .env.example .env
npm install
npx prisma migrate deploy     # создать таблицы
npx prisma db seed            # этапы воронки + 4 демо-сделки (SEED_DEMO=0 — без демо)
npm run dev                   # http://localhost:3000
```

- Прайс: 10 услуг с [progrs.ru/price](https://progrs.ru/price) (сайты, брендинг, издания); цена меняется кликом, можно добавить или удалить услугу
- В сделке услуга выбирается из прайса: подставляются направление и сумма (цена × количество для почасовых и постраничных услуг); сумма правится кликом

## Заявки с Тильды

Всё настраивается в CRM: **Интеграции → Тильда**.

1. Скопируйте адрес webhook и вставьте его в Тильде: Настройки сайта → Формы → Webhook.
   Ключ в адресе создаётся сам (при первом запуске берётся из `TILDA_WEBHOOK_KEY`, если он задан);
   его можно сменить на той же странице. Ключ также принимается полем `api_key` или заголовком `X-Api-Key`.
2. Подключите webhook к нужным формам. Тестовый запрос Тильды CRM подтверждает ответом `ok`.
3. При необходимости укажите, какие поля формы попадают в имя, телефон, email, компанию, сообщение,
   название формы и страницу. Поля из последних заявок видны там же, вместе с тем, куда они попадают.

Метки `utm_*` берутся из полей или из cookie `TILDAUTM`, номер заявки `tranid` защищает от дублей.
Остальные поля дописываются в текст лида. Журнал последних запросов (за 30 дней) показывает,
создан ли лид, был ли это повтор, проверка Тильды или запрос с неверным ключом.

## Попробовать в GitHub Codespaces

На странице репозитория: **Code → Codespaces → Create codespace**. Через несколько минут
в редакторе запустится CRM с демо-данными, а вкладка CRM (порт 3000) откроется в браузере.
Codespace предназначен для проверки: данные живут, пока он существует.
Если CRM не открылась или показывает ошибку 502, в терминале codespace выполните `bash .devcontainer/start.sh`
и дождитесь строки Ready.

## Структура

- `prisma/schema.prisma` — модели `Stage`, `Deal`, `Company`, `Contact`
- `app/deals/page.tsx` — страница воронки
- `app/deals/board.tsx` — канбан с перетаскиванием
- `app/deals/actions.ts` — серверные действия: создать, изменить, переместить, удалить
- `app/deals/deal-form.tsx` — форма сделки
- `app/clients/` — список клиентов, карточка клиента, контакты
- `app/leads/` — список лидов, карточка лида, превращение в сделку
- `app/price/` — прайс услуг; `components/product-picker.tsx` — выбор услуги и суммы в сделке
- `app/api/webhooks/tilda/route.ts` и `lib/tilda.ts` — приём и разбор заявок Тильды
- `app/integrations/` — настройки интеграций: адрес webhook, поля формы, журнал запросов
